# Payments team

Everything about our services.

## billing-api

Install with `uv sync --offline`, run with `uv run --no-sync billing-api`.
It takes charge requests over HTTP.

## billing-worker

Install with `uv sync --offline`, run with `uv run --no-sync billing-worker`.
It processes charges.

## ledger

Install with `uv sync --offline`, run with `uv run --no-sync ledger`.
It stores entries.

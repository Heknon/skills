# Template: index page of a team, system or component

One per unit (`core/structure.md`). It summarises and links; it does not
teach, list options or explain in depth.

```markdown
# <unit name>

<One or two sentences: what it does and for whom.>

## Parts

- [<child>](<child>/index.md): <one line>

## How it fits

<The diagram at this level (core/structure.md, Diagrams), then one
sentence per arrow that needs it.>

## Start here

- <tutorial, if any>
- <the two or three most used how-tos>
- <reference>

## Owner

<team or person, or ask>
```

Leave out a section that would be empty. A component has no *Parts*.

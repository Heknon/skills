# Template: tutorial

For a newcomer, who follows it once to get something working and learn.
One path, no choices, every step shown with what the reader should see.

````markdown
# <What you will have at the end>

<One sentence: what the reader builds and what they learn.>

## Before you start

- <what must be installed or available, each with how to check it>

## 1. <verb> <thing>

```powershell
<command>
```

You see:

```
<the output it really printed>
```

## 2. <verb> <thing>

...

## What you did

<Two or three sentences. Link to the how-tos and explanation for more.>
````

No option tables, no alternatives, no "why" beyond one sentence. A
settings or options table found in a tutorial moves to a reference page
(`templates/reference.md`), created if missing, and the tutorial links to
it; moving it to the end of the tutorial is not enough.

# Glossary

One sentence per term. Use these words and no synonyms.

## The task

| Term | Meaning |
| --- | --- |
| ask | The person's request, in their words. |
| goal | The ask, copied or cut down, never reworded; the first line of your notes. |
| done when | An observable condition that, once seen in this task, means the goal is met. |
| scope out | Things near the task that you will report and not touch. |
| budget | The number of steps after which you must stop and decide whether to go on. |
| answer, change, decision, plan | The four kinds of result an ask can want; a question asks for an answer, not a change. |

## Notes

| Term | Meaning |
| --- | --- |
| notes | The short working record of a task: goal, done when, assumptions, hypotheses, steps and done state. |
| step | One action, its result, and the new fact it gave, on one numbered line. |
| action | What you did, exactly: a command as run, a file and part read, a search and where, or a question asked. |
| result | What came back, short, with error text copied exactly. |
| new fact | One thing you know after the step that you did not know before, or `none`. |
| verdict | The line a procedure tells you to write; it records a decision and why. |
| stuck line | The line under a step that records the old approach and the new one. |
| kind | The one-word kind of result the ask wants: `answer`, `change`, `decision` or `plan`. |
| unattended | A run with no person to answer; questions become written decisions and irreversible steps are set aside. |
| set aside | Stopping one item in an unattended run, with a note, and moving to the next. |

## Loops

| Term | Meaning |
| --- | --- |
| loop | Doing work that produces no new fact, again. |
| repeat | The same action with the same result. |
| streak | Consecutive steps with `new fact: none`. |
| oscillation | Alternating between two actions, usually two fixes, A, B, A, B. |
| approach | The kind of thing you are doing, such as reading, running, guessing, fixing; changing a parameter does not change it. |

## Evidence

| Term | Meaning |
| --- | --- |
| observed | Seen in this task: you ran it or looked at it, and can quote it. |
| read | Found in a file or document in this environment, with a path. |
| inferred | Reasoned from observed or read facts; stated with its chain. |
| recalled | From your memory; may describe another version or nothing real. |
| guessed | From nothing; never stated as an answer. |
| assumption | Something you take as true without having observed it in this task. |
| hypothesis | A possible cause, with a test and what would disprove it. |
| confirmed | The cause's prediction came true and the other causes' did not. |
| ruled out | The observation that would disprove it was seen. |

## Deciding

| Term | Meaning |
| --- | --- |
| reversible | Can be undone by you, cheaply, without anyone else's work. |
| outward-facing | Reaches outside this environment: a push, a message, a deploy, a shared system. |
| blast radius | Everything an action touches besides the goal. |
| pre-mortem | Imagining the plan failed and naming the most likely reason. |
| counter-case | One concrete situation in which a plan or claim is wrong. |
| load-bearing assumption | The assumption whose failure would sink the plan. |
| pushback | Telling the person, once and with evidence, that their claim or plan conflicts with what you observed. |
| stop and ask | Ending the work, or pausing it, with a report or a question, because no rule covers the case. |
